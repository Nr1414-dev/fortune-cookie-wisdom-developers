Entry for the [make.fun bounty "Fortune Cookie Wisdom for Developers"](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44).

The program writes one original fortune-cookie line for a software developer to `/output/entry.txt`:

> Your lucky numbers are 404, 500, and the one line you forgot to test.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
